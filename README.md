# HireNest

HireNest is a simple job and internship discovery platform designed mainly for students and freshers.

## Features

- Search jobs by title, company, or skills
- Filter jobs by location
- Filter jobs by job type
- Filter jobs by experience
- View detailed job information
- Save/bookmark jobs
- Saved jobs persist using LocalStorage
- Simple job application form
- Responsive design
- Client-side navigation using React Router

## Technologies Used

- React.js
- JavaScript
- Tailwind CSS
- React Router
- LocalStorage
- Vite
